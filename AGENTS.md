# Repository instructions

- Maintain `codex.md` in the repository root as the running log of changes made by Codex.
- For every task that changes files, append a dated entry describing the changes, affected files, validation results, and any remaining deployment or follow-up work.
- Use dates in the user's timezone (Asia/Calcutta). Preserve existing entries.
- Record only changes made by Codex; do not attribute pre-existing user edits to Codex. Never record passwords, tokens, or other secrets.
